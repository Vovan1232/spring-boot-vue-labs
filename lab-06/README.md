# Читальня · Лабораторна робота № 6

Розширення каталогу статей з лабораторних № 3 і № 4. Сторінка «Аналітика» завантажує Excel-файли, відображає кількість статей за категоріями та частку статей за мовами.

## Запуск

У папці з файлом `compose.yaml` запустіть Docker Desktop і виконайте:

```sh
docker compose up --build
```

Відкрийте [сторінку аналітики](http://localhost:5173/analytics). Для запуску без Docker потрібні Java 17+, Maven, Node.js 22.12+ або 20.19+ та PostgreSQL. Запустіть базу `chytalnia` під користувачем `chytalnia` з паролем `chytalnia`, або задайте параметри `DB_URL`, `DB_USER`, `DB_PASSWORD`. Потім виконайте `mvn spring-boot:run` у папці `backend`, а `npm ci` і `npm run dev` у папці `frontend`. Flyway застосовує міграції під час запуску сервера.

## Імпорт

1. Натисніть «Завантажити шаблон» на сторінці «Аналітика». Файл також є у `frontend/public/template.xlsx`.
2. Перший аркуш містить заголовки `Назва`, `Автор`, `Рік`, `Категорія`, `Мова`, `Опис`. Мову потрібно вказувати як `ukr`, `eng` або `other`. Залиште приклади для демонстрації або замініть їх своїми даними.
3. Виберіть файл і натисніть «Імпортувати». Після збереження графіки оновляться без перезавантаження.
4. Повторне завантаження того самого файлу додасть його рядки знову. Повністю порожні рядки пропускаються. Якщо в рядку є помилка, весь файл відхиляється.

Ліміти становлять 2 МБ і 2 000 рядків після заголовка. Формули потрібно замінити значеннями.

## Реалізація

- `POST /api/import/excel` приймає `multipart/form-data` з полем `file`. ExcelService читає перший аркуш через Apache POI `XSSFWorkbook`, перевіряє всі рядки та викликає `saveAll`. У разі успіху відповідь має статус 201 і поле `imported`.
- `GET /api/analytics` повертає загальну кількість статей та групи `categories` і `languages` з PostgreSQL. Категорії відсортовано за кількістю записів. Діаграма відображає до 12 категорій, усі значення доступні у блоці «Дані графіка».
- Vue 3 надсилає файл через Axios і FormData. Компонент `AnalyticsChart.vue` будує діаграми Bar і Pie через Chart.js та оновлює їх після успішного імпорту.
- Міграція V2 додає рік, категорію та мову до наявної таблиці статей. Для старих записів без метаданих використано категорію «Без категорії» і мову «Не вказано».
- Використано Apache POI 5.4.1 з тієї ж гілки 5.x. Починаючи з 5.4.0, Apache POI перевіряє завантажені файли на дублікати імен записів у ZIP-контейнері. [Оновлення Apache POI](https://poi.apache.org/index.html?lang=eng)

## Приклад перевірки

У новій базі є три початкові статті. Шаблон містить шість прикладів. Після його імпорту має бути дев’ять статей, із них п’ять українською, три англійською та одна іншою мовою. Категорії «Технології», «Екологія» та «Освіта» мають по дві статті.
