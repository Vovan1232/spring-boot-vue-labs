# Лабораторні роботи зі Spring Boot і Vue 3

Навчальні застосунки «Читальня». Кожна папка містить окрему версію проєкту та власну інструкцію запуску.

| Робота | Папка | Зміст |
| --- | --- | --- |
| № 3 і № 4 | [lab-03-04](lab-03-04/README.md) | Spring Boot REST API, PostgreSQL, Vue 3, CRUD |
| № 5 | [lab-05](lab-05/README.md) | Spring AI, GPT-4o-mini, Jackson, Thymeleaf |
| № 6 | [lab-06](lab-06/README.md) | Імпорт Excel через Apache POI та графіки Chart.js |
| № 7 | [lab-07](lab-07/README.md) | Spring Security, ролі USER/MANAGER/ADMIN, BCrypt, сесії |
| № 8 | [lab-08](lab-08/README.md) | Production профіль, PostgreSQL, Docker, Nginx і підготовка HTTPS |

Звіти розміщені у папці [reports](reports/). Скріншоти та шаблон Excel містяться у відповідних проєктах.

## Запуск і перевірка

Відкрийте README потрібної роботи. Для № 3–4 і № 6 надано Docker Compose. Для № 5 і № 7 потрібні Java 17+ та Maven.

У роботі № 5 налаштовано GPT-4o-mini. Перевірку виконано з локальним імітатором OpenAI API. Для звернення до справжньої моделі потрібно задати власний OPENAI_API_KEY.

У роботі № 7 вбудована H2. Демоакаунти створюються лише з профілем demo. Їхні навчальні паролі наведено у README цієї роботи.

Роботи № 1–2 до цього набору не надано. Для № 8 підготовлено пакет розгортання та виконано локальну перевірку через Nginx і PostgreSQL. Публічний запуск і випуск сертифіката Let's Encrypt потребують віддаленого сервера та домену.
