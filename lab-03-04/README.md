# Читальня · Лабораторні роботи 3 і 4

«Читальня» — навчальний каталог статей. У лабораторній №3 реалізовано REST API на Spring Boot із PostgreSQL, а в лабораторній №4 — адаптивний клієнт на Vue 3, Vite, Vue Router, Axios і Bootstrap.

## Запуск через Docker Compose

1. Розпакуйте архів. Запустіть Docker Desktop.
2. Відкрийте термінал у папці `chytalnia`, поруч із файлом `compose.yaml`.
3. Виконайте:

   ```sh
   docker compose up --build
   ```

4. Коли сервер запуститься, відкрийте [каталог](http://localhost:5173). [REST API](http://localhost:8080/api/articles) доступний окремо.

Під час першого запуску Flyway створить таблицю та додасть три демонстраційні статті. Зміни зберігаються у томі PostgreSQL. Для зупинки натисніть Ctrl+C або виконайте `docker compose down` в іншому терміналі.

## Запуск для розробки

Потрібні Java 17+, Maven 3.6.3+, Node.js 22.12+ (або 20.19+) і PostgreSQL. За наявності Docker для запуску лише бази виконайте `docker compose up -d db`.

Якщо використовуєте встановлений PostgreSQL, створіть базу `chytalnia` та користувача `chytalnia` з паролем `chytalnia`, призначивши його власником бази. Інші параметри можна передати через змінні оточення `DB_URL`, `DB_USER`, `DB_PASSWORD`. Значення за замовчуванням призначені для локального запуску.

У першому терміналі:

```sh
cd backend
mvn spring-boot:run
```

У другому терміналі:

```sh
cd frontend
npm ci
npm run dev
```

Відкрийте [http://localhost:5173](http://localhost:5173). Vite пересилає запити `/api` на `http://127.0.0.1:8080`. Для іншого порту можна задати `API_TARGET` перед запуском Vite.

## REST API

| Метод | Шлях | Результат |
| --- | --- | --- |
| GET | `/api/articles` | 200, список записів |
| GET | `/api/articles/{id}` | 200, одна стаття або 404 |
| POST | `/api/articles` | 201, нова стаття та заголовок Location |
| PUT | `/api/articles/{id}` | 200, оновлена стаття або 404 |
| DELETE | `/api/articles/{id}` | 204 або 404 |

Для POST і PUT використовується JSON із полями `title`, `author` і `summary`. Усі поля обов’язкові. Помилка валідації повертає 400 і масив `errors` з повідомленнями.

```json
{
  "title": "Як обирати джерела",
  "author": "Ірина Мельник",
  "summary": "Короткий список ознак надійного джерела."
}
```

## Структура

- `backend/` — контролер, JPA-сутність, репозиторій, валідація та міграція Flyway.
- `frontend/` — Vue-компоненти, сторінки, маршрути, Axios-клієнт і стилі Bootstrap.
- `compose.yaml` — локальний запуск PostgreSQL, Spring Boot і фронтенду.
- `screenshots/` — сторінки, результати CRUD-операцій, помилка зв’язку й мобільна версія.

## Сценарій демонстрації

1. Перейдіть з головної сторінки до каталогу. Перевірте список початкових статей.
2. Додайте статтю. Перезавантажте сторінку та переконайтеся, що запис залишився.
3. Відредагуйте назву, збережіть зміни та перевірте оновлену картку.
4. Натисніть «Видалити», скасуйте дію, потім повторіть і підтвердьте її.
5. Відкрийте «Про проєкт» і перевірте таблицю REST API.
6. Для перевірки обробки помилки зупиніть API командою `docker compose stop api` та перезавантажте каталог. Після `docker compose start api` натисніть «Повторити запит».
