# Читальня AI · Лабораторна робота № 5

Застосунок перетворює неструктуроване бібліографічне цитування на Java Record із 37 полями. Використано Java 17, Spring Boot MVC, Spring AI, GPT-4o-mini, Lombok, Jackson і Thymeleaf.

## Запуск

Потрібні Java 17+ та Maven. Застосунок відкривається лише локально. Під час генерації текст цитування надсилається до API OpenAI.

1. Створіть ключ у [проєкті OpenAI API](https://platform.openai.com/api-keys). Для реальної генерації проєкту потрібні доступ до моделі та доступні кошти API. Зберігайте ключ поза вихідним кодом.
2. Відкрийте термінал у папці з `pom.xml`. Задайте змінну оточення `OPENAI_API_KEY` в цьому терміналі. У PowerShell можна ввести ключ приховано:

   ```powershell
   $env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', (Read-Host 'OpenAI API key' -AsSecureString)).Password
   mvn spring-boot:run
   ```

3. Відкрийте [http://localhost:8085](http://localhost:8085), натисніть «Підставити приклад», потім «Структурувати цитування». Результат і час генерації відображаються під формою. Розгорніть «Усі поля», щоб побачити весь запис.

Без ключа форма відкривається, а спроба генерації показує повідомлення про налаштування. PostgreSQL для цієї лабораторної не потрібен.

## Як працює запит

1. Форма надсилає текст до `POST /generate-all`.
2. `ChatControllerApi` формує `Prompt` із системними правилами та цитуванням, підставленим через `PromptTemplate`.
3. `OpenAiChatModel.call(prompt)` викликає GPT-4o-mini в режимі JSON. Промпт задає правила для кожного поля, обчислення кількості сторінок та визначення мови й місця публікації.
4. Контролер знімає зовнішні Markdown-маркери, якщо вони є, і читає JSON через `ObjectMapper`. Record ігнорує невідомі ключі та замінює відсутні значення на порожній рядок або `"0"`. Поле `specialized` має значення `"Category A"` за правилом завдання.
5. Thymeleaf виводить структурований результат. Якщо JSON некоректний або API недоступний, інтерфейс показує повідомлення.

Для Spring AI 1.0 використано офіційний [стартер `spring-ai-starter-model-openai`](https://docs.spring.io/spring-ai/reference/1.0/api/chat/openai-chat.html). Назву стартера з ранніх версій Spring AI наведено в завданні.

## Перевірка

```sh
mvn test
```

Інтеграційні тести використовують локальний імітатор OpenAI API. Вони перевіряють маршрут запиту, модель, JSON-режим, підстановку тексту, десеріалізацію повних і неповних даних та обробку помилок. Для тестів не потрібен справжній ключ.

Для прикладу із завдання очікуються назва «Розвиток штучного інтелекту в економіці», кількість сторінок `"11"` для діапазону 10–20, мова `"ukr"`, `published_in_ukraine = "1"` та `specialized = "Category A"`.

## Схема даних

Окремого зразка з повним переліком полів не було в наданому завданні. У Record використано всі названі в завданні ключі, а решту доповнено бібліографічними полями. Повний список і правила наведено у файлі `src/main/resources/article-prompt.txt`.
